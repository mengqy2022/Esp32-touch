# 验证记录

本文是 2026-10-14～17 开发过程的公开整理，省略个人路径、实时用量、

## 2026-10-17 设备触摸切换（当前版本）

- 电脑端版本 `2026.10.17.2`，配套固件已在 COM5 实机写入，三段哈希校验通过；应用镜像 1,570,528 字节。
- 主页用量卡片增加 CODEX／CLAUDE 两个触摸按钮，选中项高亮；下排分别显示 Token 与金额。点击调用设备自身的来源选择函数，并将选择保存在 NVS。
- 主机通过 `PC:USAGE` 分别发送两套独立数据，不自动改变选择。EXE 提供备用入口，临时释放监控串口，发送一次选择并等待设备确认，再恢复原监控状态。
- 五组主机测试共 31 项通过；增加备用入口的设备确认、无设备时不修改偏好，以及成功／失败时恢复暂停状态的覆盖。
- 实机来源回归 9 项通过：两套缓存、持续数据不覆盖选择、无效包不改变状态、切回原来源、重启记忆、重启后不复用旧计数、重启后接收新数据及无崩溃检查。测试通过串口调用与触摸按钮相同的选择函数，没有代替实体手指点击验收。
- 烧录后主页启动、四次 PING、时间同步和真实 Codex 用量接收通过。新版 EXE 独立自检及安装文件校验通过。
- 已用安装后的 EXE 选择 Claude 并取得确认；在电脑配置改为 Codex、后台重启并恢复两套真实数据后，设备仍保持 Claude，验证设备选择优先。最后通过新版 EXE 切回 Codex，COM5 在线且监控未暂停。
- 构建、缓存、临时文件、测试日志及本次升级备份继续保存在 F 盘；此前完整 Flash 备份保留。

## 2026-10-17 独立来源与金额布局验证历史

- 电脑端版本 `2026.10.17.1`。仅提供 Codex／Claude Code 两个独立来源，默认 Codex；旧 `all` 配置升级后迁移为 `codex`，设备设置与价格保留。
- 五组主机测试共 29 项通过；覆盖来源来回切换时 Token 与金额隔离、不可用来源不借用另一来源数据、旧配置迁移及控制窗口选项。
- 用量卡片上行左侧显示所选来源和 TODAY，右侧显示 EST. CNY；下行分别显示 Token 与人民币估算金额，两者均使用 16 号字体，金额有效时为绿色。来源变化会清除旧数值，等待新用量包。
- F 盘重新构建固件与 EXE。应用镜像 1,569,632 字节；COM5 实机烧录三段均通过哈希校验。烧录后主页启动、四次 PING、时间同步、真实 Codex 用量接收及无崩溃检查全部通过。
- 新版 EXE 独立自检分别返回 Codex／Claude 结果；覆盖安装后版本及文件校验一致。实际切换 Claude 再切回 Codex，均重新连接 COM5 并刷新对应来源日志，最终 Codex 在线、监控未暂停。
- 屏幕布局由控件坐标及字体定义检查，未目视验收实物画面。Claude 识别与计价使用样本测试，不以当天是否有本地记录作为验收条件。

## 后续验收建议

在干净 Windows 用户环境安装，登录后无需手动启动，插入设备自动连接；
再验证拔插、换端口、多个桥接器、串口被占用、睡眠唤醒和暂停状态跨登录保留。
连续运行至少 24 小时，测量全部相关进程的工作集、CPU、临时目录及日志占用。
进行升级／移除检查，确认设置保留或按用户选择清理，自启不残留。

重测步骤与脚本见 [开发指南](DEVELOPMENT.md)。新的结果应附测试环境和范围，
不要上传含个人用量或配置的原始报告。
