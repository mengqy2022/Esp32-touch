# 系统详细功能说明

当前系统由 ESP32 触摸设备和 PC 配套程序组成。设备绘制界面、运行本地工具；
PC 采集电脑状态和本机 Codex／Claude Code 用量，经 USB 串口发送汇总数值；
启用 PC SCREEN 后还会发送指定软件窗口的画面并接收触摸操作。
主界面使用 LVGL 控件，沿用 320×240 横屏布局，不依赖联网下载图片。

## 主界面

开机默认进入主页。先看顶栏日期／时钟与 PC ONLINE 状态，再看三个使用率圆环；
底部点 **GAME / SYSTEM / OTHER** 进入对应分类。没有配套程序或传感器数据时显示 `--`，
不影响打开设备本地功能。

| 区域 | 显示与交互 | 数据来源 |
| --- | --- | --- |
| 顶栏 | 日期、星期、Wi-Fi ON/OFF 与时钟 | 设备时间、Wi-Fi 状态；PC 同步时间和时区，也保留原 Wi-Fi 校时能力 |
| CPU | 使用率圆环、温度 | PC 主机采样；温度不支持时显示 `--` |
| GPU | 使用率圆环、温度 | NVIDIA NVML；无对应硬件／驱动时显示 `--` |
| RAM | 使用率圆环、已用／总内存 | PC 物理内存采样 |
| AI 用量 | 独立显示所选 Codex／Claude 今日 Token、`~¥` 人民币估算 | 本机 Codex／Claude Code 日志与单价配置 |
| 底部分类 | GAME、SYSTEM、OTHER | 点击打开工具分类 |

主界面持续显示，取消了旧版闲置两分钟自动切到时钟页的行为。
设备没有电池测量功能，因此不显示电池百分比。PC 监控也不要求设备连接 Wi-Fi。

### AI 用量卡片

![设备主页选中 CLAUDE 后独立显示用量与金额](images/device/home-claude.png)

**切换在设备上完成**：轻触 `CODEX` 或 `CLAUDE`，青色按钮表示当前来源。
上图演示 Claude 的 `64.0k tokens` 与 `~¥5.67`；总览图演示 Codex 的
`128.0k tokens` 与 `~¥12.34`。两组均为独立示例，不是合并统计。

- 今日 Token 按电脑本地日历日期统计，`k` 表示千个 Token。
- 总计是输入＋输出，缓存输入已包含在输入里；详细口径见
  [统计与价格](CODEX_USAGE_CN.md)。
- 已删除每日目标、限额和进度条。直接点选设备主页用量卡片上的 `CODEX`／`CLAUDE` 按钮，选中项高亮。
- 卡片上行左侧为两个触摸按钮，右侧为 `TODAY CNY`；设备记住选择，重启后恢复。
  下行左侧以 16 号字体显示 Token，右侧以 16 号字体、绿色显示估算人民币金额。
  例如 `~¥12.34` 表示约 12.34 元；Token 与金额始终来自同一个所选来源。
- 电脑分别发送两套数据，刷新和重连不会更改设备选择；EXE 中的来源切换是备用入口，发送一次设备切换指令并等待确认。
  未能完整估算显示 `~¥--`。
- 没有有效本机日志、数据过期或日期不一致时，Token 与金额显示 `--`。

## GAME：游戏

**入口：主页 → GAME。** 分类图中上排为 SUDOKU、2048，中排为 FLAPPY、SNAKE，
下排为 BREAKOUT；点名称进入游戏，右上角 **BACK** 从分类返回主页。

| 功能 | 操作与说明 |
| --- | --- |
| SUDOKU | 点击格子，用 3×3 大数字键盘填数；DEL 擦除、NEW 换题。行／列／宫格高亮、冲突标色，固定题目格不可修改。 |
| 2048 | 滑动或方向键合并数字；不同数字有不同颜色，无可移动步骤时提示结束。 |
| FLAPPY | 点击跳跃、躲避障碍；渐变背景和分数／状态提示。 |
| SNAKE | 滑动或方向键改变方向；吃食物加分、增长并逐步加速；撞墙或自身结束，填满获胜。 |
| BREAKOUT | 轻触发球，按住／滑动控制挡板；击砖得分，有剩余生命和胜负提示。 |

五款游戏可在没有 PC、Wi-Fi 和 SD 卡时使用。顶部 **II** 暂停，暂停后 **GO** 继续，
**NEW** 重新开始（数独为切换题目）。2026-10-18 更新包含游戏操作、画面和状态提示改进；
逻辑检查已通过，尚未对每款游戏完成实体触摸与画面验收。

## SYSTEM：系统工具

**入口：主页 → SYSTEM。** 分类图按三排排列：SD 与系统信息、Wi-Fi 与触摸校准、
PC 详细监控与 PC SCREEN。点工具名称进入，**BACK** 返回所属分类。
其中 PC SCREEN 需要先在电脑 EXE 选择共享窗口；选择 CALIBRATE 后还需确认才会校准。

| 功能 | 作用 |
| --- | --- |
| SD CHECK | 查看 SD 挂载与容量信息，执行扫描／读取检查，页面提供 SCAN 与 AUTO 开关。 |
| SYSTEM INFO | 查看芯片、内存及系统运行信息、Wi-Fi 连接信息，供诊断使用。 |
| WIFI | 扫描热点、输入密码、连接／断开；凭据存 NVS，保留自动重连能力。 |
| CALIBRATE | 先弹 CONFIRM/CANCEL，再进入触摸校准；校准结果保存到 NVS。也保留 BOOT 长按重校准入口。 |
| PC DETAILS | 原 PC MONITOR 详细页面：大字时钟、CPU/GPU/MEM、温度、时间来源与主机状态。点击返回主页。 |
| PC SCREEN | 查看 EXE 所选软件窗口，支持触摸点击、局部放大、平移、滚轮和网易云专用快捷控制。 |

当前字体主要适配英文和数字；不要假定 Wi-Fi 名称等任意 Unicode 文本都可完整显示。
更换屏幕／主板时需检查引脚和触摸方向，见 [硬件说明](HARDWARE.md)。

### PC SCREEN 使用方法

先在 EXE 的 **PC SCREEN** 页面搜索并共享一个窗口，再在设备打开 **SYSTEM → PC SCREEN**。
轻触目标位置后点击放大按钮，按 **2X → 4X → 8X → FIT** 循环，以最后触摸位置为中心；
轻触同时会发送左键点击。放大后拖动平移，FIT 返回全图，**UP / DN** 滚动，适合阅读 ChatGPT 长文本。
在 EXE 重新选择窗口即可切换；关闭 GUI 后后台继续传帧，返回设备其他页面停止传帧。

网易云音乐 `cloudmusic.exe` 显示 **PREV / PLAY / NEXT / VOL- / VOL+** 控制按钮，
不提供实时歌曲进度。控制响应和最小化采集取决于软件支持。
当前串口画面为 320×176，设备使用 256×140 索引缓存；细字请放大，不适合视频。
完整操作、权限与黑屏排查见 [Windows 软件手册](WINDOWS_APP_CN.md)。

## OTHER：数据与学习工具

**入口：主页 → OTHER。** 分类图上排为 INVENTORY 库存和 VOCAB LAB 学习，
下排为新增的 **SALARY CAT** 月薪猫；点名称进入，右上角 **BACK** 返回主页。
月薪猫不需要 SD 卡；库存和本地词书需要准备对应 SD 数据。

### SALARY CAT

月薪猫显示星期猫咪、今日工作时长与上下班倒计时；点击金额切换今日／本月／年薪估算。
设置全部在设备进行，支持月薪、上午／下午班次、每周工作日、中国调休、日期例外和开机页面。
默认 6,000 元、09:00–12:00／14:00–17:00，原主页仍为默认开机页。
2026 年调休已内置；其他年份未覆盖会提示并按每周规则计算，未校时不计算。
完整口径、设置步骤和日历导入见 [月薪猫手册](SALARY_CAT_CN.md)。

### INVENTORY

元器件库存存于 SD 卡，标准交换格式为 UTF-8 `PRODUCT_NO,MODEL,QTY`。
设备提供库存浏览、筛选／搜索、数量加减和删除等已有操作。
配套 `tools/inventory_tool.py` 可通过串口管理文件和处理支持的库存／BOM CSV；
`tools/material_to_inventory.py` 可合并采购文件并导出标准库存。

个人订单、库存和备份留在本地。模板仅作为公开示例。
库存串口工具与后台监控不能同时打开一个串口，先在 EXE 中暂停监控。

### VOCAB LAB

- BOOKS：浏览 SD 词书；保留在线词书下载入口，下载需要 Wi-Fi 和可用的数据源。
- LEARN：查看单词、释义、例句，通过 AGAIN／SHOW／KNOWN 完成学习与复习。
- DICTATION：触屏默写界面，使用 CLEAR、ADD、DEL、CHECK 等控件输入与检查。
- PLAN：调整每日学习目标并保存；学习进度保存在 SD，计划设置保存在 NVS。
- SD：进入 SD 检查，用于排查词书不可见或未挂载问题。

本地词书和学习不需要网络。词书流式读取并建立索引，避免把整本词书加载到 RAM。
默写使用轻量的手写／输入处理，未接入云端 OCR。格式和准备方法见
[词书说明](VOCABULARY.md)。

## 导航与数据更新

工具 BACK 返回所属分类，分类 BACK 返回主页；词书、学习、默写、计划等
子页面先返回 VOCAB LAB。主界面无需操作即可继续显示监控数据。

| 数据 | 默认刷新／有效期 | 失效行为 |
| --- | --- | --- |
| PC 使用率、内存、温度 | 约每秒采样；5 秒无新 STAT 即过期 | 显示 PC OFFLINE，过期数值清空为 `--` |
| Codex／Claude 日志与费用 | 约每 5 秒重新统计／估算；包随采样循环发送 | 90 秒无包或日期不符显示 NO DATA |
| PC 时间 | 首次连接立即同步，随后约每 15 秒同步 | 断开后设备继续运行本地时钟；断电后需再次校时 |
| USB 设备发现 | Windows 后台约每 2 秒检查 | 未插设备等待，识别到设备再连接 |

PC SCREEN 与遥测共用 115200 串口，复杂帧传输会延迟采样包，上表频率不代表传帧期间的保证值。
传感器不支持与设备离线是两种情况：PC 可以在线，但 CPU 温度仍显示 `--`。
Codex 包不会把已经过期的 PC 使用率重新标记为在线。

## 系统数据存放位置

| 位置 | 内容 |
| --- | --- |
| 设备 NVS | Wi-Fi 凭据、触摸校准、时区与部分设置 |
| SD 卡 | 库存／BOM、词书、学习进度 |
| PC Codex／Claude 目录 | 各自的本机会话日志，由对应程序生成 |
| PC 运行目录 | EXE、后台配置、价格配置、运行日志和暂停状态；默认 LocalAppData，可配置为其他磁盘 |

固件的串口接收已修复“一次接收多行时只处理第一行”的问题。
PC、SCREEN 与 FILE 协议由同一个 UART 读任务分发，详见 [协议](PROTOCOL.md)。
EXE 操作、NO DATA 和串口冲突排查见 [Windows 手册](WINDOWS_APP_CN.md)。
