# 系统详细功能说明

当前系统由 ESP32 触摸设备和 PC 配套程序组成。设备绘制界面、运行本地工具；
PC 采集电脑状态和本机 Codex 用量，经 USB 串口发送汇总数值。
主界面使用 LVGL 控件，沿用 320×240 横屏布局，不依赖联网下载图片。

## 主界面

| 区域 | 显示与交互 | 数据来源 |
| --- | --- | --- |
| 顶栏 | 日期、星期、Wi-Fi ON/OFF 与时钟 | 设备时间、Wi-Fi 状态；PC 同步时间和时区，也保留原 Wi-Fi 校时能力 |
| CPU | 使用率圆环、温度 | PC 主机采样；温度不支持时显示 `--` |
| GPU | 使用率圆环、温度 | NVIDIA NVML；无对应硬件／驱动时显示 `--` |
| RAM | 使用率圆环、已用／总内存 | PC 物理内存采样 |
| CODEX | 今日 Token、个人目标进度、`~¥` 人民币估算 | 本机 Codex 会话日志与单价配置 |
| 底部分类 | GAME、SYSTEM、OTHER | 点击打开工具分类 |

主界面持续显示，取消了旧版闲置两分钟自动切到时钟页的行为。
设备没有电池测量功能，因此不显示电池百分比。PC 监控也不要求设备连接 Wi-Fi。

### CODEX 卡片

- 今日 Token 按电脑本地日历日期统计，`k` 表示千个 Token。
- 总计是输入＋输出，缓存输入已包含在输入里；详细口径见
  [统计与价格](CODEX_USAGE_CN.md)。
- 默认个人目标为 0，即不启用目标。配置目标后显示当日消耗／目标的进度，
  显示上限为 100%。它是用户自行设定的参考值。
- 原 LOCAL 显示位置替换为估算人民币金额。例如 `~¥12.34` 表示约 12.34 元。
  未能完整估算显示 `~¥--`。
- 没有有效本机日志、数据过期或日期不一致时显示 NO DATA。

## GAME：游戏

| 功能 | 操作与说明 |
| --- | --- |
| SUDOKU | 点击格子、选择数字，DEL 擦除可编辑格，NEW 切换题目；固定题目格不可修改。 |
| 2048 | 使用页面方向键合并数字，目标是形成更大的方块。 |
| FLAPPY | 点击控制跳跃，躲避障碍；具体状态提示由页面显示。 |

游戏可在没有 PC、Wi-Fi 和 SD 卡时使用。游戏实现沿用已有代码，
本次调整分类与返回路径，未重新设计游戏规则。

## SYSTEM：系统工具

| 功能 | 作用 |
| --- | --- |
| SD CHECK | 查看 SD 挂载与容量信息，执行扫描／读取检查，页面提供 SCAN 与 AUTO 开关。 |
| SYSTEM INFO | 查看芯片、内存及系统运行信息、Wi-Fi 连接信息，供诊断使用。 |
| WIFI | 扫描热点、输入密码、连接／断开；凭据存 NVS，保留自动重连能力。 |
| CALIBRATE | 先弹 CONFIRM/CANCEL，再进入触摸校准；校准结果保存到 NVS。也保留 BOOT 长按重校准入口。 |
| PC DETAILS | 原 PC MONITOR 详细页面：大字时钟、CPU/GPU/MEM、温度、时间来源与主机状态。点击返回主页。 |

当前字体主要适配英文和数字；不要假定 Wi-Fi 名称等任意 Unicode 文本都可完整显示。
更换屏幕／主板时需检查引脚和触摸方向，见 [硬件说明](HARDWARE.md)。

## OTHER：数据与学习工具

### INVENTORY

元器件库存存于 SD 卡，标准交换格式为 UTF-8 `PRODUCT_NO,MODEL,QTY`。
设备提供库存浏览、筛选／搜索、数量加减和删除等已有操作。
配套 `tools/inventory_tool.py` 可通过串口管理文件和处理支持的库存／BOM CSV；
`tools/material_to_inventory.py` 可合并采购文件并导出标准库存。

个人订单、库存和备份留在本地。模板仅作为公开示例。
库存串口工具与后台监控不能同时打开一个串口，先在 EXE 中暂停监控。

### VOCAB LAB

- BOOKS：浏览 SD 词书；保留在线词书下载入口，下载需要 Wi-Fi 和可用的数据源。
- LEARN：查看单词、释义、例句，通过 AGAIN／SHOW／KNOWN 完成学习与复习。
- DICTATION：触屏默写界面，使用 CLEAR、ADD、DEL、CHECK 等控件输入与检查。
- PLAN：调整每日学习目标并保存；学习进度保存在 SD，计划设置保存在 NVS。
- SD：进入 SD 检查，用于排查词书不可见或未挂载问题。

本地词书和学习不需要网络。词书流式读取并建立索引，避免把整本词书加载到 RAM。
默写使用轻量的手写／输入处理，未接入云端 OCR。格式和准备方法见
[词书说明](VOCABULARY.md)。

## 导航与数据更新

工具 BACK 返回所属分类，分类 BACK 返回主页；词书、学习、默写、计划等
子页面先返回 VOCAB LAB。主界面无需操作即可继续显示监控数据。

| 数据 | 默认刷新／有效期 | 失效行为 |
| --- | --- | --- |
| PC 使用率、内存、温度 | 约每秒采样；5 秒无新 STAT 即过期 | 显示 PC OFFLINE，过期数值清空为 `--` |
| Codex 日志与费用 | 约每 5 秒重新统计／估算；包随采样循环发送 | 90 秒无包或日期不符显示 NO DATA |
| PC 时间 | 首次连接立即同步，随后约每 15 秒同步 | 断开后设备继续运行本地时钟；断电后需再次校时 |
| USB 设备发现 | Windows 后台约每 2 秒检查 | 未插设备等待，识别到设备再连接 |

传感器不支持与设备离线是两种情况：PC 可以在线，但 CPU 温度仍显示 `--`。
Codex 包不会把已经过期的 PC 使用率重新标记为在线。

## 系统数据存放位置

| 位置 | 内容 |
| --- | --- |
| 设备 NVS | Wi-Fi 凭据、触摸校准、时区与部分设置 |
| SD 卡 | 库存／BOM、词书、学习进度 |
| PC Codex 目录 | 现有会话日志，由 Codex 生成 |
| PC LocalAppData | EXE、后台配置、价格配置、运行日志和暂停状态 |

固件的串口接收已修复“一次接收多行时只处理第一行”的问题。
PC 与 FILE 协议由同一个 UART 读任务分发，详见 [协议](PROTOCOL.md)。
EXE 操作、NO DATA 和串口冲突排查见 [Windows 手册](WINDOWS_APP_CN.md)。
